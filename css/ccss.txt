1.What is CSS?
Cascading Style Sheets is used to style HTML elements.

p {
  color: blue;
  font-size: 16px;
}



2.Difference between inline, internal, and external CSS
Type	How Applied	Example
Inline	Directly in tag	<p style="color:red;">Text</p>
Internal	Inside <style> tag	<style>p {color:red;}</style>
External	Separate CSS file	<link rel="stylesheet" href="style.css">



3.What is the difference between id and class in CSS?

id → Unique, #idName {}

class → Reusable, .className {}



4.What is the difference between relative, absolute, fixed, and sticky positioning?
Position	Behavior
relative	Position relative to original place
absolute	Position relative to nearest positioned ancestor
fixed	Stays in same position on screen
sticky	Sticks when scrolling after a threshold




5.CSS Box Model

Definition:
The css box model is the every HTML element is represented as a rectangular box in the browser.
It consists of 4 layers:

Content – The actual content (text, image, etc.)

Padding – Space inside the element between content and border

Border – The edge around the padding

Margin – Space outside the element between border and other elements



6.Types of CSS (inline, internal, external)? Which is recommended?

Inline: Written inside the tag using style="". (Low reusability)

Internal: Written inside <style> in HTML. (Applies to one page only)

External: Written in a .css file and linked. (Best practice, reusable, improves maintainability)
👉 External CSS is recommended.


7. Difference between relative, absolute, fixed, and sticky positioning?

static → default, no positioning.

relative → relative to its normal position.

absolute → relative to the nearest positioned ancestor.

fixed → relative to viewport, stays even on scroll.

sticky → acts like relative until a scroll threshold, then sticks like fixed.


8.z-index? When it doesn’t work?

z-index controls the stacking order of elements.

Works only when position is not static.


9.display: none vs visibility: hidden?

display: none → removes element from DOM flow. (No space)

visibility: hidden → hides but keeps space occupied.


10.Flexbox vs CSS Grid

Flexbox is a one-dimensional layout system, useful when we need to align items either in a row or in a column, like navigation bars or button groups.
Grid, on the other hand, is a two-dimensional system, which allows us to control both rows and columns at the same time, making it better for page layouts, dashboards, or galleries.

In real projects, I usually combine both — I use Grid to structure the page and Flexbox inside smaller components for alignment.
