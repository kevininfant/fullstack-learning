introductory HTML questions and answers
------------------------------------------

1. What is HTML?
Answer: HTML (HyperText Markup Language) is the standard language used to create and design web pages.
 It structures the content of a webpage using elements like headings, paragraphs, links, images, etc.

 2. What does HTML stand for?
Answer: HTML stands for HyperText Markup Language.



📜 History of HTML
🔹 What is HTML?
HTML stands for HyperText Markup Language. It is the standard markup language used to create and structure web pages on the internet.

📆 Timeline of HTML Versions
✅ 1. HTML 1.0 (1991)
Created by Tim Berners-Lee at CERN.

First version of HTML.

Very basic — supported simple text formatting, links, and images.

✅ 2. HTML 2.0 (1995)
Published by IETF (Internet Engineering Task Force).

Standardized basic HTML elements.

Introduced forms, input elements.

✅ 3. HTML 3.2 (1997)
Introduced by W3C (World Wide Web Consortium).

Added support for:

Tables

Applets

Scripts (JavaScript)

Text alignment and styles

✅ 4. HTML 4.01 (1999)
Improved structure and formatting.

Added support for:

CSS (Cascading Style Sheets)

Frames and scripting

Three versions: Strict, Transitional, Frameset

✅ 5. XHTML (2000)
Reformulated version of HTML using XML rules.

More strict and structured.

Less popular due to complexity and browser incompatibility.

✅ 6. HTML5 (2014 Official Release)
Major update by W3C and WHATWG.

Focused on:

Semantics (<article>, <section>, etc.)

Multimedia (<video>, <audio>)

APIs (Canvas, Geolocation, Web Storage)

Mobile-first & responsive design

Still evolving and used widely today.

🧠 Who Invented HTML?
Sir Tim Berners-Lee, a British scientist.

Created the first HTML specification and the World Wide Web in 1989-1991.

🎯 Why HTML Is Important Today
It is the foundation of all websites.

Every web page you visit is structured with HTML.

Works with CSS (design) and JavaScript (interactivity).

📜 History of CSS
✅ CSS1 – 1996
Introduced by Håkon Wium Lie and Bert Bos.

Standardized by W3C.

Provided basic styling: fonts, colors, margins, borders, etc.

Supported only simple layout control.

✅ CSS2 – 1998
Added more sophisticated features:

Positioning (absolute, relative)

Media types (screen, print)

Z-index

Table layout styling

Had better support for accessibility and print.

⚠️ CSS2.1 (2004 - Finalized in 2011)
Refined version of CSS2, removed poorly supported features.

Became a stable base for browsers.

✅ CSS3 – 2011–Present
Introduced modular structure (Box Model, Flexbox, Grid, etc.).

Key Features:

Media queries for responsive design

Transitions, animations

Shadows, gradients

Web fonts

Evolved continuously with new modules being added independently.

✅ CSS4 – Not officially a single spec
No formal CSS4 version.

Instead, W3C continues to develop CSS as independent modules (e.g., CSS Grid Level 2, CSS Selectors Level 4).

📆 CSS Timeline Overview
Year	Version	Key Features
1996	CSS1	Basic styling (colors, fonts)
1998	CSS2	Positioning, media types, z-index
2011	CSS2.1	Bug fixes and browser compatibility
2011+	CSS3	Modular, responsive design, animations

🌐 Who Created CSS?
Håkon Wium Lie proposed CSS in 1994.

Became W3C standard in 1996.

🧠 Why Is CSS Important?
Makes websites attractive, consistent, and user-friendly.

Enables responsive and accessible web design.

Used in all frontend development — alongside HTML & JavaScript.

1.What is HTML?

HyperText Markup Language used to create and structure web pages.

<h1>Hello Infosys!</h1>
<p>Welcome to HTML interview prep.</p>



2.. Difference between HTML and HTML5

HTML5 is latest version, supports audio, video, canvas, semantic tags.


3.What are semantic tags in HTML?

1.Tags that give meaning to content.

2.Examples: <header>, <footer>, <article>, <section>, <nav>



3.Difference between <div> and <span>

<div> → Block element, full width

<span> → Inline element, only content width



4.What are self-closing tags?

Tags that don’t need a closing tag.

Examples: <br>, <hr>, <img>, <input>




5.Difference between <strong> and <b>

<b> → Bold text (styling)

<strong> → Important text (semantic + bold)





6.Difference between <i> and <em>

<i> → Italic text (styling)

<em> → Emphasized text (semantic + italic)




7.Difference between <ul>, <ol>, <dl>

<ul> → Unordered list

<ol> → Ordered list

<dl> → Description list



8.Difference between <a> and <link>

<a> → Hyperlink, navigates to page

<link> → Link external resources (CSS, favicon)

<link rel="stylesheet" href="style.css">
<a href="https://infosys.com">Go to Infosys</a>




9.What are meta tags?

Provide information about web page.

<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="Infosys HTML interview prep">





11.Difference between id and class

id → unique, used once per page

class → reusable, can use on multiple elements




12.What is the difference between <script> in head and body?

Head: Script executes before page renders → may block page

Body (end): Page loads first, script executes after content


13.What are data attributes in HTML?

Custom attributes to store extra info: data-*

<div data-id="101" data-role="admin">Kevin</div>



14.Difference between <canvas> and <svg> in HTML5?

Canvas → Pixel-based, good for dynamic graphics, games.

SVG → Vector-based, scalable, good for icons, charts.


15.How do you handle SEO in HTML?

Use semantic tags.

Proper meta tags (<meta name="description">).

Use heading hierarchy (<h1>, <h2>).

Use meaningful alt text in images.

Proper <title> tag.



16.What are web storage APIs in HTML5? When will you use them?

localStorage → Data Stored permanently in browser.

sessionStorage → Data lost after tab close.

Use case: Storing user preferences, theme, cart items.


17.What is the difference between inline SVG and an image <img src="icon.svg">?

Inline SVG can be styled with CSS and manipulated with JS.

<img> just displays the file, no styling control.


18.How would you improve performance of an HTML page?

Use minified CSS/JS.

Use CDN for static assets.

Use image optimization (WebP).

Use lazy loading (loading="lazy" on <img>).

Use <link rel="preload"> for critical resources.



19.What’s the difference between <iframe> and <embed>?

<iframe> → Embeds another HTML document inside.

<embed> → Embeds external resources (like PDF, Flash, multimedia).


20.How do you ensure cross-browser compatibility in HTML?

Use <!DOCTYPE html> (HTML5 standard).

Test in multiple browsers.

Use polyfills/shims for unsupported features.

Avoid deprecated tags.


21.What are Progressive Web Apps (PWA) and how does HTML help?

PWA = Web apps that behave like native apps (offline, push notifications).

HTML supports Service Workers + Manifest (<link rel="manifest" href="manifest.json">).



22.Explain the difference between cookies, localStorage, and sessionStorage with examples.

Cookies: Small data, sent with each request, expires manually.

localStorage: Stored permanently in browser.

sessionStorage: Stored until tab/browser is closed.

localStorage.setItem("theme", "dark");
sessionStorage.setItem("user", "Kevin");


23.What is the difference between GET and POST in forms?

GET → Data in URL, less secure, used for search.

POST → Data in body, secure, used for sensitive info (login).


24.If your website loads slowly, what HTML improvements will you do?

Use defer/async for JS.

Use preload for fonts & CSS.

Use lazy loading for images.

Minify HTML, use gzip.


25.What are the differences between HTML Entities and Unicode?

Entities: Named codes (&lt;, &gt;, &copy;).

Unicode: Direct character (©, ✓).


26.What’s the difference between inline, block, and inline-block elements?

Block: Takes full width, starts new line (<div>, <p>).

Inline: Doesn’t break line, only as wide as content (<span>, <a>).

Inline-block: Behaves inline but can set height/width.


27.What is the difference between rendering HTML on client-side vs server-side?

Server-side rendering (SSR) → HTML built on server, faster first load, SEO friendly.

Client-side rendering (CSR) → HTML shell + JS builds DOM, slower first load, better interactivity (React, Angular).


28.What is the difference between DOM, Virtual DOM, and Shadow DOM?

DOM: Browser’s object model of HTML.

Virtual DOM: In React, a JS copy of DOM for fast diffing.

Shadow DOM: Encapsulation in Web Components (styles won’t leak).


29.What is the difference between alt, title, and aria-label?

alt → alternative text for images (required for SEO + screen readers).

title → tooltip text on hover.

aria-label → accessibility description (not visible).


30.What is the difference between relative units (em, rem, %) and absolute units (px, pt)?

em → relative to parent font size.

rem → relative to root (html) font size.

% → relative to parent.

px → fixed pixels.
