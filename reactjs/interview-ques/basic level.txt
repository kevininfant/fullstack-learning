1.What is React?

React is an open-source JavaScript library developed by Facebook (Meta) for building fast and interactive user interfaces,
It uses a virtual DOM for fast rendering and is mainly used to build single-page applications.

3.Functional vs Class Components?

“Functional components are simple JavaScript functions that use Hooks to manage state and lifecycle,
 while class components are ES6 classes with built-in lifecycle methods and this.state. 
 Functional components are preferred in modern React since they are easier to read, test, and optimize,
 while class components are considered legacy but still supported.”

4. What is the difference between state and props?
Props: Data passed from a parent to a child component. They are read-only and immutable.
meaning a child component cannot change the props it receives.

State: Data managed within a component. It is mutable and causes a component to re-render when it changes.

example:

// Parent component
function ParentComponent() {
  const userName = "Alice";
  return <ChildComponent name={userName} />;
}

// Child component
import React, { useState } from 'react';

function ChildComponent(props) {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>Hello, {props.name}!</p>
      <p>Button clicked {count} times.</p>
      <button onClick={() => setCount(count + 1)}>
        Click me
      </button>
    </div>
  );
}

6. Explain the Virtual DOM.

Answer: The Virtual DOM is a lightweight copy of the real DOM. When a component's state changes,
 React updates the VDOM first, then compares it to the previous version to find the minimal number of changes needed.
 It then applies only those changes to the real DOM, which is much faster than re-rendering everything.

 7.What are Keys in React?

Keys in React are unique identifiers assigned to elements in a list.
 They help React optimize rendering by efficiently determining which items changed, were added, or removed during reconciliation. 
The best practice is to use a stable and unique value like an id, rather than array index, to ensure predictable behavior.

const users = ["Kevin", "John", "Sophia"];

{users.map((user, index) => <li key={index}>{user}</li>)}

8.Controlled vs Uncontrolled components?

"In real projects, controlled components are preferred because they give better control, validation, and predictable behavior.
 But uncontrolled components are simpler when you just need the value once, like in a form submission.

 Example:

 Example (Controlled Input):

 import { useState } from "react";

function ControlledInput() {
  const [name, setName] = useState("");

  return (
    <div>
      <input 
        type="text" 
        value={name}   // React controls the value
        onChange={(e) => setName(e.target.value)} 
      />
      <p>Your name: {name}</p>
    </div>
  );
}


Example (Uncontrolled Input):

import { useRef } from "react";

function UncontrolledInput() {
  const inputRef = useRef();

  const handleSubmit = () => {
    alert("Your name: " + inputRef.current.value);
  };

  return (
    <div>
      <input type="text" ref={inputRef} />  {/* DOM stores the value */}
      <button onClick={handleSubmit}>Submit</button>
    </div>
  );
}

 11.how many hooks in react and which is most usaables?
 
React has two categories of hooks:

1. Basic (Core) Hooks

These are built into React itself and used most often:

useState

useEffect

useContext

useRef

useReducer

useCallback

useMemo

useImperativeHandle

useLayoutEffect

useDebugValue

useId

useTransition (introduced in React 18 for concurrent features)

useDeferredValue (React 18)

useSyncExternalStore (React 18)

useInsertionEffect (React 18)

👉 So, React has around 15+ official hooks (depending on React version).

2. Custom Hooks

You can create your own hooks (functions that start with use) to reuse logic.

Example: useFetch, useLocalStorage, etc.

🔹 Most Usable Hooks (the “Top 5” you’ll use daily)

useState → for managing component state

useEffect → for side effects (fetching data, subscriptions, timers)

useContext → for global state/context (like auth, theme)

useRef → for accessing/managing DOM elements or persisting values without re-render

useMemo & useCallback → for performance optimization (memoizing values and functions)

✅ In practice:

Beginners mostly use useState + useEffect (almost every component).

Intermediate/Advanced projects often use useContext, useReducer, useMemo, useCallback.

 11.what is useSates?

 useState is a React Hook that allows you to add state to functional components. 
 It provides a state variable and a function to update it, and when the update function is called,
  React re-renders the component with the new value. 
  It's the most common way to manage dynamic data in a functional component.

Example:

const [count, setCount] = useState(0);

// ...
<button onClick={() => setCount(count + 1)}>
  Clicked {count} times
</button>

12.what is useeffect?

useEffect is a React Hook that allows you to perform "side effects" in your functional components. 
Side effects are any actions that affect something outside of the component itself, such as fetching data from an API,
 manually changing the DOM, or setting up subscriptions.

Example: Fetching Data

import React, { useState, useEffect } from 'react';

function DataFetcher() {
  const [data, setData] = useState(null);

  // This effect runs once when the component mounts
  useEffect(() => {
    fetch('https://api.example.com/data')
      .then(response => response.json())
      .then(result => setData(result));
  }, []); // The empty dependency array ensures this effect runs only once

  return <div>{data ? <p>Data loaded!</p> : <p>Loading...</p>}</div>;
}
